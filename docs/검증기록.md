# 0.1.0 검증 범위

실제 학생 개인정보 없이 가상 자료를 사용했다.

- 대량 스캔: 30명×3쪽, 1면1→30/2면30→1/3면1→30 대응.
- 작업 저장·복원·선택 출력·규칙 갱신 통합 검증:30항목. 89쪽 부분본+보완1쪽의 고유90쪽 재구성·재개방을 포함한다. 90쪽 전체를 새로 래스터 출력한 시험은 아니다.
- 창 크기·Tk 배율 조합45건 배치 확인.
- 버튼 시각 안내:56개 상태·스타일 확인과 메인·보존11개 확인. 기존 버튼 명령/활성 상태/문구, 스타일 크기·포커스 상속, 예외 상태·복원·콜백 정리 검사.
- 마지막 로컬 후보에서 기존 가상 작업을 복원하고 원본54쪽의 TEST-03-007·3반·페이지순번2를 선택1쪽 출력해 재개방 확인.
- 처리·연결·페이지 정보·작업 저장·병합 엔진의 보존을 소스 해시로 확인. 사용자 원본·기존 Beta·기존 백업도 보존했다.
- 0.1.0 게시 준비에서는 화면 제목의 후보 표시 두 곳만 제거했다. GitHub Actions의 별도 릴리스 검사는 source compile/import, Tk 기본 화면, 합성 명단·PDF, 소켓 차단 출력과 재개방, 배포 ZIP 구조·해시를 확인한다. 실행 결과는 Actions 이력과 build-manifest에서 확인한다.

로컬 시험과 CI, 외부 검수는 구별한다. OS 배율·고대비 테마·다른 PC 전체에 대한 인증이나 침투시험을 수행하지 않았다. 본문 개인정보 자동 탐지는 제공하지 않는다.
