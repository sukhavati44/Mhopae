# 무명호패 0.1.0

학생코드·학급·페이지순번을 바탕으로 대량 답안 PDF를 연결하고, 필요한 단위로 묶거나 나눌 수 있습니다.

- 구간별 정순/역순과 페이지 대응 확인, 미정·중복의 명시적 관리
- 두 박스 머리글과 PDF 내부 페이지 정보, 학급/학생/페이지순번 단위 재구성
- 작업 저장·이어하기, 입력 파일 변경 확인, 미저장 종료 확인
- 필요한 페이지만 보완 출력, 전체 대응을 먼저 검사하는 중복 방지
- 메인 절단·마스크 규칙을 비교하고 개별 예외를 보존하거나 교체
- 기존 버튼의 작동 조건을 유지하는 은은한 시각 안내

`MHopae-0.1.0-windows-x64.zip` 전체를 풀고 `MHopae/MHopae.exe`를 실행하십시오. 같은 폴더의 `_internal`이 필요합니다. `SHA256SUMS.txt`와 빌드·소스 명세를 함께 제공합니다.

기존 Beta 파일과 사용자 원본은 별도로 보존하십시오. 본문 개인정보는 자동 탐지하지 않으며 실제 제거 범위·학생 대응은 사용자가 확인합니다. 입력·명단·로컬 작업 JSON은 이 공개 릴리스에 포함하지 않습니다.

검증은 가상 자료로 수행했습니다. 30명×3쪽의 정순/역순/정순 대응, 선택 보완 출력, 메타데이터 재구성, 작업 복원 및 UI 표시를 확인했습니다. GitHub Actions에서도 합성 PDF/XLSX와 오프라인 출력·재개방을 검사합니다. 모든 PC·보안 제품 환경을 검증한 것은 아닙니다.
