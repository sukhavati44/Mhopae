무명호패 v0.1.0 배포 후보 — 최종 사용 승인 전

실행: candidate\MHopae\MHopae.exe
원래 Beta 0.0.1과 바탕화면 바로가기는 변경하지 않았습니다.

1. 기존처럼 명단과 PDF를 열고 코드를 대상에 추가합니다.
2. 편집 기본은 전체 공통 규칙입니다. 절단선 모드에서 원본을 클릭해 수평 절단선을 정합니다.
3. 마스크 추가 모드에서 드래그하면 사각형을 여러 개 추가합니다. 반투명 빨강은 편집 화면 전용이며 출력에는 흰색 픽셀만 남습니다.
4. 마스크 이동·크기 모드: 사각형 안을 드래그해 이동, 우하단 핸들을 드래그해 크기 조절, 선택 마스크 삭제 버튼으로 제거합니다.
5. 절단 개별/마스크 개별 체크는 현재 원본 페이지를 전체 규칙에서 분리합니다. 체크 해제하면 전체 규칙으로 돌아갑니다. 예외 이동 목록은 원본 페이지 번호와 절단/마스크 종류를 표시하며 선택 즉시 같은 화면에서 이동합니다.
6. 좌표는 회전 후 보이는 페이지의 가로·세로 비율입니다. 페이지 크기가 다르면 같은 비율로 적용됩니다. 다른 위치의 신원 영역은 개별 예외로 조정하십시오. 확대 메뉴와 마우스 휠로 확인합니다.
7. DPI 선택은 300/400. 모든 페이지 원본 JPEG의 명시 밀도(JFIF/EXIF)가 동일한 300/400일 때만 자동 선택합니다. 미확인·비표준·충돌은300, 사용자가 바꾸면 현재 PDF의 페이지 이동 동안 유지됩니다. 새 PDF는 새 원본 기준으로 초기화됩니다. 이미지 배치에서 역산한 유효 DPI를 원본 명시 DPI로 표시하지 않습니다. 필기 정보나 OCR 정확도 개선을 보장하지 않습니다.
8. 결과 미리보기에서 절단·마스크·학생 대응을 확인한 뒤 개별/묶음 PDF를 생성합니다. 규칙 변경은 확인 상태를 무효화합니다. 이 프로그램은 본문 개인정보를 자동으로 찾아 지우지 않습니다.

학생별 독립 병합
- 상단 학생별 PDF 병합 메뉴. 원본 스캔과 명단을 미리 열 필요 없이 이미 비식별화된 단일 페이지 PDF 폴더만 선택하면 됩니다.
- 기본: 코드.pdf, 코드002.pdf, 코드003.pdf 순. all/코드(all).pdf 생성.
- 기존 코드표는 선택 보조 옵션이며 이름·학생 신원 대응표를 새로 생성하지 않습니다.
- 중복·누락 순번, 여러 기준 코드로 해석되는 파일명, 코드표 불일치, 손상/암호화/복수페이지 입력, 기존 출력 충돌은 보류합니다. 올바른 코드표 지정 또는 입력 정리를 하십시오.
- 코드가 숫자로 끝나는 등 이름 자체가 모호하면 추정하지 않습니다. 파일명 규칙을 지켰는지는 사용자가 확인해야 합니다. 폴더 직접 하위 PDF만 처리하며 all 하위는 다시 입력하지 않습니다.
- 병합은 새 비식별화가 아닙니다. 입력이 이미 비식별화됐는지 별도로 확인하십시오.

페이지 정보·대량 스캔 대응 (2026-11-03 추가)
- 대량 스캔 대응·출력 → 파일 넣기 → 스캔 방식 → 대응 확인·출력 순서입니다.
- 학생당 한 페이지 / 학생별 연속(학생당 쪽수) / 페이지순번별 묶음 중 선택합니다.
- 30명 90쪽이 1쪽 정순·2쪽 역순·3쪽 정순이면 페이지순번별 묶음 → 자동 나누기 → 두 번째 구간 역순 → 선택 구간에 적용 → 대응표 만들기를 누릅니다.
- 출력 가능한 행의 코드·학급·페이지순번과 미리보기를 확인하고 확인 체크 후 저장합니다. 절단·마스크는 메인 전체 규칙 및 같은 파일의 개별 예외를 사용합니다.
- 미정 행은 나중에 지정, 중복 스캔은 이번 출력에서 제외할 수 있습니다. 나머지 정상 행은 계속 출력하며 뒤 학생의 코드를 당기지 않습니다.
- 여러 행 선택 후 적용은 기존 코드·학급을 유지하고 페이지순번만 변경합니다. 미정 코드는 한 장씩 지정하십시오.
- 페이지순번은 학생 답안 내 순번이며 묶음 PDF의 물리적 페이지 번호와 다릅니다.
- 출력 상단 왼쪽 박스는 학생코드, 오른쪽 박스는 학급·페이지순번입니다. 같은 정보가 각 페이지 내부에 함께 저장됩니다. 이름·출석번호는 내부 정보에 넣지 않습니다.
- 정보로 묶기·나누기에서는 이미 비식별화한 PDF 여러 개를 불러와 학급별/학생별/페이지순번별/페이지별로 새 파일을 만들 수 있습니다.
- 정보 재구성은 추가 개인정보 제거 기능이 아닙니다. 정보 없는 외부 형식의 연결을 수동 변경하면 기존 표시가 남을 수 있으므로 미리보기를 확인하십시오.
- 내부 정보는 암호나 진위 인증이 아닙니다. 외부 편집·인쇄 재저장 때 손실될 수 있습니다. 기존 파일은 덮어쓰지 않으며 입력 폴더와 다른 폴더에 저장합니다.
- 상세 케이스·검증·한계: PAGEINFO_CASE_REPORT.md, scan_cases/case_results.json, scan_cases/gui_verification.json.

초보자 GUI 개선 (2026-11-03 UX)
- 대량 작업은 ① 자료 불러오기 → ② 스캔 순서·연결 확인 → ③ 출력 확인·저장입니다.
- 스캔 방식을 고르면 묶음이 자동 제안됩니다. 선택 묶음의 정순·역순을 바꾸면 연결도 즉시 갱신됩니다. 정상 자료에 별도 구간 적용·대응표 만들기 클릭은 필요 없습니다.
- 범위·누락·부분 스캔 조정은 상세 조정에서 기존 수동 기능을 사용하십시오. 방향 변경만으로 누락 위치를 추정하지 않습니다.
- 학생 찾기에 이름·번호·코드를 입력하고 목록에서 학생을 선택한 뒤 적용합니다. 검색어 자체를 코드로 저장하지 않습니다. 이름·번호는 로컬 화면 전용이며 PDF에는 코드·학급·페이지순번만 들어갑니다.
- 상단 미정/중복/제외 개수를 누르면 해당 페이지만 표시됩니다. 선택하여 연결 수정·나중에 지정·제외·다시 포함할 수 있습니다. 이전 페이지로 복귀와 변경 되돌리기를 사용할 수 있습니다.
- 출력 방식 선택 후 예상 파일·쪽수·파일명 예시를 확인하십시오. 출력 폴더를 먼저 선택하고 요약·미리보기를 검토한 뒤 체크 → 저장을 누릅니다.
- 현재 미저장 변경사항과 직전 저장 결과는 별도로 표시됩니다. 수정하면 확인 체크가 해제됩니다. 현재 표시 정보는 자동 비식별 인증이나 교사 승인 완료를 뜻하지 않습니다.
- 자세한 조작·검증 범위: UX_REPORT_v1.md.

[GUI 추가 세부조정 / 2026-11-03]
① 파일 목록은 입력 순서·쪽수·파일명을 표시하며 창 높이에 맞게 늘어납니다. 자동 정렬하지 않습니다.
② 카드 제목 또는 다구간 표의 행을 선택하면 실제 첫·끝 원본을 나란히 표시합니다. 예상 학생은 추정입니다. 역순을 바꿔도 원본 영상은 바뀌지 않습니다. 작은 창·큰 글자에서는 오른쪽 세로 스크롤로 보조 미리보기를 확인합니다.
③ 기본은 검토 중심입니다. ‘선택 페이지 수정’과 ‘저장 준비’로 필요한 패널만 펼칩니다. 미정·중복 행은 수정 패널이 자동으로 열립니다. 접어도 현재 설정·미저장 표시는 유지됩니다.
미리보기는 ‘페이지 맞춤’이 기본입니다. 세부 확인은 ‘너비 맞춤’, +/−, 스크롤을 사용합니다. 원본 보기/비식별 출력 보기는 같은 원본 페이지를 비교합니다.
표/미리보기 사이 ⋮ 손잡이를 드래그하여 너비를 바꿉니다. 긴 코드·파일명은 열 너비나 가로 스크롤, 전체 정보 표시를 함께 확인합니다.


[2026-11-03 FOLLOWUP: 작업 저장과 선택 출력]
대량 스캔 창 위쪽의 작업 저장으로 연결·미정·제외·역순 구간·절단/마스크 설정을 로컬 local_work/*.mhopae.json에 저장합니다. PDF 출력과 작업 저장은 별개입니다. 작업 이어하기로 불러오고 출력 미리보기를 다시 확인하십시오. 원본 PDF나 명단이 이동·변경되면 해당 연결은 보류되며 자동 재대응하지 않습니다. 작업 파일에는 로컬 경로와 코드 참조가 있으므로 외부에 전달하지 마십시오. 이름·번호는 작업 파일에 저장하지 않습니다.

메인 절단/마스크 변경 후 메인 규칙 갱신을 눌러 비교하고 현재 개별 예외 보존 / 메인 규칙으로 교체 / 현재 대량 규칙 유지 중 선택합니다. 학생 연결은 유지되며 출력 확인은 다시 해야 합니다. 규칙 되돌림은 직전 갱신 한 단계입니다.
