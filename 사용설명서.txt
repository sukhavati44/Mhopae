무명호패 Beta 0.0.1 — PDF 비식별화 도구
MHopae.exe와 _internal 폴더를 함께 보관합니다. Python 별도 실행 없이 EXE로 시작합니다.

1. 명단 XLSX 열기: 시트·코드 열을 한 창에서 선택합니다. 코드 열 빈칸은 자동 인식입니다.
   학급(반), 번호, 이름(성명)이 필요합니다. 기존 코드는 유지합니다.
2. 코드가 없는 행만 선택해 ‘빈 코드 발급’을 누릅니다. 선택이 없으면 전체 명단의 미발급 행을 확인 후 발급합니다.
   ‘대조표 보기’로 대응을 확인하고 ‘대조표 새 파일 저장’으로 로컬에 보관합니다.
   PDF 폴더와 분리하십시오. 신규 발급 코드는 저장 전 PDF를 생성할 수 없습니다.
3. 후보에서 학생을 선택해 ‘대상에 추가 ↓’를 누릅니다. 아래 처리 대상 순서가 PDF 페이지 순서입니다.
   Ctrl/Shift로 복수 선택하고 제외·다시 추가·위/아래 이동할 수 있습니다.
   제외는 이번 작업에서만 적용됩니다. 학생 행·코드·원본 파일을 삭제하지 않습니다.
4. 원본 PDF 열기: 페이지를 이동하고, 원본 화면에서 절단선을 클릭합니다. 선 위의 영역을 제거합니다.
   본문 개인정보를 자동 판독하지 않으므로 답안 보존과 개인정보 제거를 직접 확인합니다.
5. 결과 미리보기: 학급·번호·이름·코드를 함께 대조할 수 있습니다. 학생정보는 교사용 화면 전용입니다.
   출력 PDF에 추가되는 식별 텍스트는 코드뿐입니다.
   이전/다음으로 탐색하고 ‘이 페이지의 절단·학생 대응 확인’을 눌러 확인을 기록합니다.
   이동만으로 확인되지 않습니다. 첫 페이지와 다른 표본 페이지를 확인해야 PDF 생성이 활성화됩니다.
   기존과 같이 1페이지 PDF는 그 한 페이지 확인으로 준비됩니다.
   명단/순서/절단선/해상도/역순 설정 변경 시 확인이 무효화됩니다.
6. 학생코드별 개별 PDF 또는 하나의 묶음 PDF를 선택하고 ‘PDF 생성’을 누릅니다.
   원본 PDF·실명 대조표와 분리된 로컬 출력 폴더를 선택합니다. 기존 파일은 _02, _03 순번으로 보존합니다.

동작하지 않는 버튼 옆/화면 아래의 다음 단계 안내를 확인하십시오. 창 크기가 작으면 두 목록의 스크롤을 사용합니다.
모든 작업은 로컬·오프라인입니다. 실명 대조표를 외부로 보내지 마십시오.
이 검수판은 기존 v0.6 운영본과 v0.7 기능검수판을 교체하지 않습니다.

[명단 후보 제외·복구·순서]
- 후보를 선택하고 「후보 제외」를 누르면 후보에서 숨깁니다. 이미 처리 대상에 넣은 학생도 함께 빠지므로 페이지·ID 개수를 다시 확인하십시오.
- 「제외 후보만 보기」를 켜고 학생을 선택한 뒤 「후보 복구」를 누르십시오. 보기를 해제하면 기존 후보 위치에 돌아옵니다. 처리 대상에는 자동 추가하지 않습니다.
- 「후보 ↑」「후보 ↓」로 후보 순서를 조정할 수 있습니다. 이후 「대상에 추가」할 때 조정한 순서를 사용합니다. 이미 추가된 처리 대상의 순서는 바뀌지 않습니다.
- 후보 제외와 순서 조정은 현재 작업에만 적용됩니다. 원본 엑셀의 행·이름·학생코드는 변경하지 않으며 새 명단을 열면 초기화됩니다.
